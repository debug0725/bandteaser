# 원숭이 손 — 나폴리탄 괴담 게임

정적 HTML/CSS/JavaScript로 제작된 모바일 우선 분기형 웹게임입니다.

## 포함 기능

- ACT 1~7 구조
- 약 45개 선택지
- 6개 일반 엔딩
- TRUE END `160 소페르`
- HIDDEN END `열 번째 손님`
- 키워드 입력 및 한국어 조사 자동 처리
- 반복 선택/수칙 위반에 따른 오염도 상승
- 오염도에 따른 글자 깨짐, 특수문자, 검은 블록 효과
- 수칙서 아카이브
- 결과 이미지 PNG 저장
- 모바일 최적화
- localStorage 기반 엔딩 실패 기록

## 실행

`index.html`을 브라우저에서 열면 됩니다.

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. Vercel에서 새 프로젝트를 만들고 저장소를 연결합니다.
3. Framework Preset은 `Other`로 두고 배포합니다.
4. Build Command는 비워 둡니다.
5. Output Directory는 `.`로 둡니다.

## TRUE END 조건

- 시계를 한 번도 보지 않기
- 질문을 정확히 세 번 하기
- C의 기록 끝까지 복원하기
- 5번 수칙이 거짓임을 간파하기
- 오염도 55% 미만
- 마지막 대가로 `자신의 소원` 선택
