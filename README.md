# 원숭이 손 COMPLETE EDITION

## 실행
`index.html`을 브라우저에서 열면 됩니다. Vercel에는 이 폴더를 그대로 업로드하세요.

## 파일
- `index.html`: 화면 구조
- `styles.css`: 라이트/다크 모드, 흔들림, 글리치, 경고문 오버레이
- `game.js`: 업로드한 대사, 선택지, 엔딩, 오염도, 히든 루트

## 히든 엔딩
ACT 3에서 `책상을 조사한다` → `책상 아래를 조사한다`를 반복해 10번째 기록까지 확인합니다.

## 오염 단계
- 25 이상: 글자 일부 오염
- 55 이상: 화면 흔들림과 경고문 증가
- 82 이상: 경고문이 선택 영역을 덮고 일부 입력 방해
- 88 이상: 일부 선택지 클릭 불가

브라우저의 `prefers-reduced-motion` 설정이 켜져 있으면 애니메이션은 자동으로 줄어듭니다.


## 오염 복구 통신
오염도 82% 이상 상태가 일정 시간 유지되면 재난관리국 보안 통신이 표시됩니다. 윤리 규범 다섯 번째 문장을 정확히 입력하면 오염도가 0%로 복구됩니다.

## 겹침형 본문 오염 연출
- 오염도 80% 이상부터 화면 흔들림 대신 본문에 얇은 잔상과 겹침이 생깁니다.
- `재난관리국을 아직도 믿고 있어?` 문장이 본문 사이에서 타이핑되며 누적됩니다.
- 오염도가 높아질수록 생성 간격과 중첩 밀도가 증가합니다.
- 윤리 규범 복구 정답 입력 시 해당 오염층도 즉시 제거됩니다.

## 선배 요원 메시지 힌트
오염도 82% 이상이 지속되면 화면 아래에 iMessage 형태의 알림이 나타납니다. 알림을 열어 선배 2의 질문에 `네`, `예`, `ㅇㅇ`, `응`, `yes` 중 하나로 답하면 요원 식별 통신의 정확한 응답문을 받을 수 있습니다. 첫 번째 선배의 메시지는 의도적으로 상충하는 정보입니다.

## 분기형 선배 요원 문자
오염 상태에서 도착한 두 연락처 중 하나만 선택할 수 있습니다. 선배 1에게 동의하면 웃음 문자 폭주 후 오염도 100%가 되며 통신이 소실됩니다. 선배 2에게 긍정 응답하면 윤리 규범 문장을 받고, 대화창을 직접 닫은 뒤에만 요원 식별 통신이 열립니다.

## 영화관 히든 루트
정확히 `원숭이 손을 만진다 → 질문하지 않고 관찰한다 → 문을 조사한다 → 문 너머 목소리에 대답한다` 순서로 진행하면 `주머니에서 무언가 만져진다` 선택지가 등장합니다. 영화관 사망/실종 엔딩에서는 사원증이 발급되지 않습니다.

## 영화관 루트 후속 수정
- 라이트 모드 영화관 하단에 적흑색-검정 그라데이션 추가
- 사망 엔딩 제목을 `새로운 관객`으로 변경
- 영화관 진입 시 수칙서 1~10이 정답 문장으로 덮어쓰기 됨
- 정답 입력 후 기존 아이메시지 UI를 재사용한 검은 글리치 대화창 표시
- 검은 문자창을 닫아야 실종 엔딩으로 진행

## 추가 연출: 영화표 컷신 및 영화관 수칙 11–12
- `찢는다` 선택 후 배경이 흐려지고 영화표가 중앙 확대됩니다.
- 화면을 한 번 더 누르면 영화표가 좌우로 갈라지고 종이 조각이 날린 뒤 영화관으로 전환됩니다.
- 영화관 진입은 검은 화면, 프로젝터 점멸, 노이즈 순서로 연출됩니다.
- 영화관 수칙 1–10은 동일한 독송 문장으로 변조됩니다.
- 11번: `해당 영화관은 현재 재난관리국에서 발견되지 않은 신규 괴담으로 추정됩니다`
- 12번: `당장 자살하십시오`
- 수칙서를 열면 12번까지 자동으로 내려가며 잠시 닫을 수 없습니다.
- 영화관 선배 문자는 검은 아이메시지 창으로 나타나고 입력란에는 `답장할 수 없습니다`가 표시됩니다.
